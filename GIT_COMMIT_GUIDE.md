# TypingPro Git Commit Guide: v1.2.1 Hotfix

This guide provides the necessary Git commands to commit and push the recent authentication and startup fixes.

## 📝 Commit Strategy

Since the changes address both a fatal crash and a performance stall, it is recommended to use a single "feat" or "fix" commit, or split them into two logical parts.

### Option 1: Unified Commit (Recommended)

```bash
git add apps/desktop/src/hooks/useAuth.ts apps/desktop/src/App.tsx
git commit -m "fix(desktop): fix auth crash and optimize startup performance

- Wrapped onDeepLinkOpenUrl in try-catch to prevent crash.
- Refactored App.tsx init sequence to be non-blocking.
- Reduced splash screen time and improved TTI."
```

### Option 2: Split Commits

**1. The Auth Fix**

```bash
git add apps/desktop/src/hooks/useAuth.ts
git commit -m "fix(desktop): wrap deep link listener in defensive try-catch"
```

**2. The Performance Fix**

```bash
git add apps/desktop/src/App.tsx
git commit -m "perf(desktop): optimize startup sequence for non-blocking UI"
```

## 🚀 Pushing Changes

```bash
# Push to current branch
git push origin your-branch-name

# Or create a hotfix branch
git checkout -b hotfix/v1.2.1-auth-stall
git add .
git commit -m "fix: resolve critical auth crash and startup stall"
git push origin hotfix/v1.2.1-auth-stall
```

## 🏷️ Tagging the Release

Once merged, tag the release:

```bash
git tag -a v1.2.1 -m "Hotfix for auth crash and startup stall"
```
